# Architecture Decision Records

One file per decision, named by what was decided. Each record gives the date, status (proposed, accepted,
superseded by …), the context, the decision, its consequences and the alternatives that were rejected. A decision
that changes is not edited away: a new record supersedes it and the old one says so.
